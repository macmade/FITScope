Improvements

Generated — 2026-06-27

A working list of improvements for FITScope, the macOS FITS image viewer. The points span the rendering pipeline, the inspector's image-processing controls, the information panels, and new image-adjustment features.

Roadmap

  1. Verify light mode appearance

    Check how the app looks in light mode and fix any contrast, color, or layout issues so it is on par with dark mode.

  2. Prioritize selected file for rendering

    When a file is selected, give it priority in the rendering pipeline so the image the user is looking at is processed first.

  3. Gamma — remove the on/off switch

    The gamma control does not need an enable switch: a value of 1 is already a no-op, so it can be the default with no separate toggle.

  4. Info view — no wrap, ellipsis with tooltips

    Stop wrapping long values in the info view; truncate them with an ellipsis and show the full value in a tooltip on hover.

  5. Review order of processors

    Revisit the order in which image processors are applied in the rendering pipeline to make sure it is correct and produces the expected result.

  6. Review order of controls in inspector

    Revisit the order of the controls shown in the inspector so it follows a logical, intuitive workflow.

  7. Gamma vs. levels gamma — do we need both?

    Evaluate whether the standalone gamma correction and the gamma (midtone) adjustment inside levels are redundant, and decide whether to keep both.

  8. Curves and levels windows — sizes and positions

    Review and refine the default sizes and on-screen positions of the curves and levels windows, and how they are persisted.

  9. Visible planets in info view (letters)

    Show which planets are visible in the information view, identified by their letters.

  10. Sunsets and sunrises (civil, nautical, astronomical)

    Display sunrise and sunset times, including the civil, nautical, and astronomical twilight phases.

  11. Reset on inspector controls (cross button?)

    Add a way to reset individual inspector controls to their default value — possibly via a small clear/cross button on each control.

  12. Denoise

    Add a denoise image-processing adjustment.

  13. Sharpen

    Add a sharpen image-processing adjustment.

  14. “Open in” menu (original and processed)

    Add an “Open With” menu to open the image in an external application, for both the original FITS file and the processed/rendered image.

  15. Window toolbar?

    Investigate whether it is worth adding a proper window toolbar to surface some of the controls.

  16. Add hue to saturation

    Extend the saturation control with a hue adjustment.

  17. Color balance (low, mid, high)

    Add a color balance control acting on shadows (low), midtones (mid), and highlights (high).

  18. Histogram backdrop on curves?

    Consider drawing a histogram backdrop behind the curves editor, as is already done in the levels editor.

  19. Before/after slider on image

    Add a before/after comparison slider over the image to compare the original and the processed result.

  20. Info panel — selectable labels

    Make the labels in the information panel selectable so their text can be copied.

  21. Star detection info presentation

    Decide how to present star detection information — inline/overlay, in the info panel, or in a dedicated section.

  22. Ensure debouncing with image renderer

    Make sure rendering requests are properly debounced so rapid control changes do not trigger redundant renders.

  23. Regroup levels and curves into one control

    Levels and curves currently sit on separate lines; regroup them inside a single control with both buttons on the same line.
