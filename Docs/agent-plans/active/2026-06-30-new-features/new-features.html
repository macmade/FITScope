New Features

Generated — 2026-06-30

New features planned for FITScope, the macOS FITS image viewer. These span additional image-processing adjustments, an offline plate-solving path, and the integration of several standalone astrophotography tools into FITScope.

Roadmap

  1. Denoise

    Add a denoise image-processing adjustment.

  2. Sharpen

    Add a sharpen image-processing adjustment.

  3. Local plate solving with GAIA data

    Add an offline plate-solving path backed by a GAIA-derived star catalog that can be downloaded from Preferences. When the catalog is installed, solve locally against it; when it is not, keep using nova.astrometry.net as today. If the local GAIA solve fails, fall back to nova as well.

  4. Include AstroTools

    Bring the astrophotography computation tools from the standalone AstroTools app — HFR to arc seconds, exposure-time equivalence, magnification, and similar calculations — into FITScope as an extra tool/window.

  5. Include GroupPictures

    Import the standalone GroupPictures app to organize pictures on the filesystem, grouping them by date, exposure, ISO, or other keywords, as a separate tool/window.

  6. Include MovieGenerator

    Import the standalone MovieGenerator app to generate timelapses and movies from sequences of still images, as a separate tool/window.

  7. Include PhotoConverter

    Import the standalone PhotoConverter app to batch convert images between formats (PNG, JPEG, TIFF, RAW, …) inside FITScope, as a separate tool/window.

  8. Include YouplaBoum

    Import the standalone YouplaBoum app for quickly culling and rejecting pictures — similar to Blink in PixInsight — as a separate tool/window.
