FITS Writing

Generated 2026-07-11

Items gathered around the upcoming FITS write capability in the SwiftFITS submodule. Once FITScope can produce FITS files rather than only read them, several parts of the app can be improved — from a proper FITS export option, to smarter plate-solving uploads, to simplifying the current XISF keyword handling.

Backlog

1

Offer FITS as an export format

SwiftFITS will gain the ability to write FITS files. Once it does, expose a FITS option when exporting an image, so users can save to FITS as well. The option should be offered for every source except files that are already FITS, where re-exporting to the same format adds nothing.

2

Upload a FITS file for plate-solving XISF images

When submitting a file for plate-solving, non-FITS sources are currently uploaded as a PNG. For XISF images we could instead generate a FITS file carrying the correct metadata. Providing that metadata to nova.astrometry.net would most likely speed up the solve, since it would no longer be a blind solve when the relevant information is available.

3

Simplify XISF embedded FITS keyword handling

To parse the FITS keywords embedded in XISF files, we currently build FITS cards by hand. This approach is imperfect — particularly around padding. With the new SwiftFITS write capabilities, this handling could be simplified and made more robust.
