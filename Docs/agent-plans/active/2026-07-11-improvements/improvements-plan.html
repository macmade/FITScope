This plan turns the 12-item FITScope improvements backlog into independently reviewable and committable milestones — one milestone per backlog item, as requested. Each milestone carries its own status, completion date, implementation notes, automated-review findings, and human review comments so it can be updated in place as work proceeds.

The milestones are reordered relative to the backlog's numbering to sequence them by dependency and quick-win value: isolated UI wins first, then a warnings/stability cleanup pass, then rendering and processing behavior, and finally the FITS-write feature cluster (which shares the FITS/SwiftFITS subsystem and is best built together). Each milestone notes its original backlog number. The mapping between plan order and backlog order is summarized in the appendix.

Implementation notes

Implemented with TDD, after an investigation-first pass characterised the bug and two design decisions were confirmed with the user up front.

Root cause (why it looked wrong / was over-sensitive). BrightnessContrast ran on the normalized linear buffer, before the non-linear STF stretch (PixelPipeline.processors(): Normalize → WhiteBalance → BrightnessContrast → Stretch → …). Linear astro data lives almost entirely near black (background ~0.001–0.05; only stars spike toward 1), so the transform clip( (v − 0.5)·contrast + 0.5 + brightness ) — which pivots contrast about the 0.5 midpoint and adds brightness in that same linear domain — is nowhere near where the data sits: a contrast of 1.5 on a background pixel at v≈0.01 gives (0.01 − 0.5)·1.5 + 0.5 = −0.235 → clips to black; a contrast of 0.5 lifts the same pixel to 0.255 (near-black background jumps to mid-gray). Because B/C ran before the aggressive stretch, the stretch then amplified every change. The formula was fine — the domain was wrong.

Design decisions (confirmed with the user). (1) Transfer function: keep the linear scale-about-0.5 formula unchanged (it is correct once it acts in the display domain) and instead retune the UI slider ranges to be gentle. (2) Placement: run B/C right after the stretch — the first display-referred adjustment, ahead of gamma/levels/curves.
