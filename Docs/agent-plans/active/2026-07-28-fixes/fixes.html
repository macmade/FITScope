A short backlog of defects observed while using FITScope: an overlay that is not always correctly registered to the image right after loading, and an unexpected system permission prompt at launch.

Backlog

  1. Stars overlay is sometimes misaligned right after loading an image

    After loading an image and toggling the stars overlay on, the star markers are sometimes drawn slightly off from the stars they mark. Zooming in or out corrects the alignment, and it stays correct afterwards. Whether the other canvas overlays are affected in the same way has not been checked.

  2. Unexpected "access data from other apps" prompt at launch

    Launching the app now triggers the system prompt asking for permission to access data from other applications. FITScope should not require this, and the prompt should not appear at all.
