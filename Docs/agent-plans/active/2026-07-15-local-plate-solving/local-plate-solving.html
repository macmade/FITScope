Local Plate Solving

Generated 2026-07-15

An offline plate-solving path for FITScope, backed by a GAIA-derived star catalog. Today FITScope solves against nova.astrometry.net; this initiative lets the user solve locally against a GAIA catalog they provide, keeping the online service as a fallback so solving keeps working whether or not a local catalog is installed. The solving logic will be added in the SwiftAstro submodule, which is in scope to modify for this work.

Roadmap

  1. Offline plate-solving path

    Add a local plate-solving path backed by a GAIA-derived star catalog, so images can be solved without contacting an online service.

  2. Reference user-provided GAIA catalog files

    The GAIA catalog files are not downloaded by FITScope. The user downloads them themselves and, in Preferences, references (points FITScope at) the files on disk.

  3. Solve locally when the catalog is available

    When a GAIA catalog has been referenced in Preferences, solve locally against it instead of contacting the online service.

  4. Keep nova.astrometry.net when no catalog is set

    When no local GAIA catalog is referenced, keep using nova.astrometry.net as today.

  5. Fall back to nova on local failure

    If a local GAIA solve fails, fall back to nova.astrometry.net so solving still has a chance to succeed.
