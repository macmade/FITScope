Astro Tools

Generated 2026-07-15

Bring the astrophotography computation tools from the standalone AstroTools app into FITScope, and let users register their own equipment so those computations can be run against their real gear.

Roadmap

  1. Include AstroTools

    Bring the astrophotography computation tools from the standalone AstroTools app — HFR to arc seconds, exposure-time equivalence, magnification, and similar calculations — into FITScope as an extra tool/window.

  2. User-defined equipment setups

    Let users add their own setups — telescopes, cameras, and related gear — either from Preferences or a dedicated window, so those setups can be selected and used to drive the computations.
