  1. Hot-pixel rejection for unstretched min/max normalization

    Unstretched images are normalized using min/max scaling, which is fragile because a single hot pixel skews the range and degrades the displayed result. Percentile normalization is not an acceptable substitute, as it renders the image unfaithfully. The fix is to keep min/max normalization but introduce hot-pixel rejection into the pipeline so outlier pixels no longer distort the range. This most likely belongs in the SwiftPixel submodule; submodule work is acceptable.
