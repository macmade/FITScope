Formats

Generated 2026-07-06

A backlog of additional input formats and geometries FITScope should be able to open, beyond the current single two-dimensional FITS image (NAXIS=2). It covers other FITS geometries (NAXIS=1 and NAXIS=3), the XISF format, and common photographic formats. Several items build on shared UI pieces — notably a multi-image carousel and the FITS keyword info window, which is generalized to display each format's own metadata.

Backlog

  1. NAXIS=1 support (1D data as a graph)

    Support one-dimensional FITS data (NAXIS=1). Rather than an image, display it as a graph using Swift Charts. Adapt the chart based on CTYPE1 when it is present and when doing so is relevant to how the axis should be presented.

  2. NAXIS=3 support (separate RGB channels)

    Support three-dimensional FITS data (NAXIS=3) where the third axis holds separate RGB channels, combining them into a single color image. Requires CTYPE1 and CTYPE2 to be present and their contents validated, with no CTYPE3.

  3. NAXIS=3 support (multiple images)

    Support three-dimensional FITS data (NAXIS=3) where the third axis holds multiple distinct images. Validate the configuration on CTYPE, rejecting unknown or unsupported configurations. Display the additional images in a carousel below the main image view, allowing the user to select and display each one.

  4. XISF file support

    Support XISF files using the SwiftXISF submodule available in SwiftAstro, ignoring its display function. Include XISF metadata and adapt the FITS keyword info window to present it. Since XISF files may contain multiple images, reuse the image carousel built for NAXIS=3 multiple images.

  5. TIFF, PNG, and JPEG support

    Support TIFF, PNG, and JPEG files. Include their metadata and adapt the FITS keyword info window to present it (for example EXIF and similar).

  6. RAW support

    Support RAW files. Include their metadata and adapt the FITS keyword info window to present it (for example EXIF and similar).

  7. HEIC support

    Support HEIC files. Include their metadata and adapt the FITS keyword info window to present it (for example EXIF and similar). Since HEIC files may contain multiple images, reuse the image carousel built for NAXIS=3 multiple images.
