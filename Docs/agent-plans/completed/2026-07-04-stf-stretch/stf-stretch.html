STF Stretch

Generated — 2026-07-04

Backlog centered on a histogram-based auto-stretch (a PixInsight-style screen-transfer function) for FITScope, and on wiring that automatic stretch into the places where a sensible default rendering matters most — opening images, star detection, and system previews.

Backlog

  1. Histogram-based auto-stretch (STF)

    A one-click screen-transfer stretch that derives the midtones-transfer parameters from the image statistics (PixInsight-style: shadow clip = median − 2.8 · MAD, target background = 0.25) instead of the user hand-tuning. To be implemented in the SwiftPixel submodule.

  2. Auto-stretch-on-open preference (per format)

    Add a preference to enable applying the new auto-STF stretch automatically when opening images, configurable per format. FITS is the only format today, with PNG, JPEG, TIFF, RAW, and XISF planned. Note that XISF can carry a display function, so auto-stretch should be applied only when no display function is present.

  3. Auto-stretch before star detection

    Apply the auto-STF stretch prior to running star detection, to get more reliable detection results.

  4. Auto-STF for QuickLook and Finder previews

    Use the default STF stretch when generating QuickLook and Finder previews (the preview and thumbnail extensions), so previews render with a sensible default stretch.
