Improvements

Generated — 2026-06-29 · Updated — 2026-07-04

A working list of improvements for FITScope, the macOS FITS image viewer. The points span the rendering pipeline, the inspector's image-processing controls, the information panels, and new image-adjustment features.

Roadmap

  1. Prioritize selected file for rendering

    When a file is selected, give it priority in the rendering pipeline so the image the user is looking at is processed first.

  2. Visible planets in info view (letters)

    Show which planets are visible in the information view, identified by their letters.

  3. Sunsets and sunrises (civil, nautical, astronomical)

    Display sunrise and sunset times, including the civil, nautical, and astronomical twilight phases.

  4. Reset on inspector controls (cross button?)

    Add a way to reset individual inspector controls to their default value — possibly via a small clear/cross button on each control.

  5. “Open in” menu (original and processed)

    Add an “Open With” menu to open the image in an external application, for both the original FITS file and the processed/rendered image.

  6. Window toolbar?

    Investigate whether it is worth adding a proper window toolbar to surface some of the controls.

  7. Add hue to saturation

    Extend the saturation control with a hue adjustment.

  8. Color balance (low, mid, high)

    Add a color balance control acting on shadows (low), midtones (mid), and highlights (high).

  9. Before/after slider on image

    Add a before/after comparison slider over the image to compare the original and the processed result.

  10. Star detection info presentation

    Decide how to present star detection information — inline/overlay, in the info panel, or in a dedicated section.

  11. Overlay customization in Preferences

    Add a Preferences tab for customizing the overlays, letting the user define the color and opacity of each overlay individually.

  12. Session metric trends (SNR, star count, FWHM/HFR)

    Plot per-file metrics that are already computed — SNR, star count, FWHM/HFR — against acquisition order or DATE-OBS using Swift Charts, to spot focus and seeing drift and passing clouds across a session.

  13. Sky-quality / background indicator

    Surface the robust sky background that is already estimated during star detection (and via HistogramStatistics) as a relative light-pollution / sky-brightness read-out in the info panel.
