Stacking

Generated 2026-06-28

A roadmap for adding an image-stacking workflow to FITScope. Today FITScope is a FITS viewer; this initiative brings a full astrophotography stacking pipeline — selecting and calibrating frames, weighting and rejecting them, plate-solving, and producing a stacked result — with rich inspection and progress tools along the way.

Roadmap

  1. Dedicated stacking window

    Create a new window that hosts the entire image-stacking workflow, separate from the main viewer.

  2. Frame selection by type

    Let the user choose and add frames by their role in the pipeline: dark, bias, flat, dark flat, and light frames.

  3. Image weighting formula

    Use the image-weighting formula defined in preferences, with the option to edit or change it just for the current stacking session without altering the global preference.

  4. Basic image info

    Display basic information about each image being added to the stack.

  5. Rejection settings

    Allow the user to choose the rejection settings used during stacking — both pixel rejection and frame rejection.

  6. Plate-solving settings

    Allow the user to configure plate-solving settings and provide hints to guide the solve.

  7. Image statistics graphs

    Show image statistics as graphs across the set — weights, star counts, FWHM, HFR, eccentricity, and similar metrics.

  8. Detailed progress view

    Provide a detailed progress view that surfaces the stacking steps as they run, including which frames are rejected.

  9. Session groups

    Allow creating groups for multiple night sessions, so lights, darks, flats, and other frames can be organized per session.

  10. Destination folder

    Let the user choose the destination folder where the stacking output is written.

  11. Open result on completion

    When stacking finishes, automatically open the saved stacked result in a new window.

  12. Pre-stack process review

    Show the stacking process steps before stacking begins, so they can be reviewed — either as a separate step or as a dedicated view while configuring and adding frames.

  13. Frame browser with blink & exclude

    In the statistics view, list all files with a fast preview, and let the user blink between frames and manually exclude individual files from the stack.
